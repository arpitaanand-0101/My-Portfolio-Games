# 🌌 Nebula Matrix: The Arcade Hub

Welcome to **Nebula Matrix**, a premium, retro-minimalist local gaming ecosystem. This repository serves as a centralized arcade cabinet hub housing a suite of highly customized, atmospheric web simulations built entirely using vanilla frontend architecture.

The entire catalog is tied together by a central landing dashboard featuring a vintage CRT-scanline monitor aesthetic, dark-obsidian canvases, and fluid, responsive navigation.

## 🎨 System Design & Architecture

* **Zero Asset Overhead:** Ambient soundscapes and mechanical click feedback tones are synthesized programmatically on-the-fly using the native browser **Web Audio API**. No heavy external `.mp3` dependencies.
* **CRT Scanline Layer:** The central landing dashboard utilizes layered gradients and sub-pixel text shadowing to replicate the warm, nostalgic flicker of a 90s tabletop arcade monitor.
* **Directory-Linked Router:** Seamlessly jump forward into specialized game cabinets and retreat back to the mainframe dashboard using clean, relative file-path anchors (`../index.html`).
